# Controlador de Motorista - Uber/99

**App 100% privado - Dados salvos apenas no navegador via localStorage.**

## Funcionalidades
- 🛡️ Registro de custos operacionais e fixos (combustível, seguro, IPVA, pedágios)
- 🚗 Lançamento diário rápido (KM, faturamento Uber/99, horas, despesas)
- 💰 Cálculo automático de lucro líquido, lucro/km, lucro/hora
- 📈 Gráficos de desempenho e histórico de 30 dias
- ⚡ Alertas automáticos de metas (semanal/mensal)
- 📤 Exportação CSV e backup em JSON
- 📱 Design responsivo (funciona como PWA no celular)

## Instalação

```bash
npm install
npm run dev
npm run build
```

Deploy: `gh repo create` + `gh pages deploy`
